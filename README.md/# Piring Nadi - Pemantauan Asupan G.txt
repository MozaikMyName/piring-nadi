# Piring Nadi - Pemantauan Asupan Gizi Harian

PiringNadi dipilih sebagai nama aplikasi karena menggambarkan keterkaitan antara asupan makanan dalam ‘Piring’ dengan kodisi Kesehatan dan kehidupan yang dilambangkan oleh ‘Nadi’. Aplikasi ini membantu penggunaan memantau asupan gizi, lemak dan kalori harian agar tercipta pola hidup yang lebih sehat dan seimbang.
Sistem ini membantu pengguna memantau asupan kalori, lemak, dan protein yang dikonsum sisetiap hari. Pengguna mencatat makanan yang dimakan beserta porsinya, lalu sistem menghitung total nutrisi secara otomatis dan membandingkan dengan target gizi harian. Sistem juga memberikan saran perbaikan gizi apabila asupan tidak sesuai target. Aplikasi dibangun menggunakan konsep OOP di Java dan terhubung langsung ke database MySQL.
